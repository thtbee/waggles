# Entity

A meditative real-time scene, built with Three.js.

**[Launch the demo](https://thtbee.github.io/waggles/entity/)**

---

### States

The unbound · Padmasana · tapas

### Controls

| | |
| --- | --- |
| Drag | Orbit |
| Scroll | Move closer |
| Click the water | Ripples |
| Tap the figure | Pulse |
| Hold on the figure | Awaken |
| `Space` or **Awaken** | Transition between states |
| `M` | Sound |
| `H` | Hide the interface |
| `F` | Fullscreen |

### Run locally

From the repo root, with Python 3:

```bash
python tools/serve.py
```

Then open [localhost:8000/entity](http://localhost:8000/entity/).
